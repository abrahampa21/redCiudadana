# Sistema de Gestión de Reportes Ciudadanos
## Descripción

El Sistema de Gestión de Reportes Ciudadanos es una aplicación web desarrollada para permitir que los ciudadanos reporten incidencias dentro de su comunidad y que las autoridades puedan gestionar, clasificar y dar seguimiento a dichos reportes hasta su resolución.

El objetivo principal es centralizar la información de problemas comunitarios, facilitar su atención y mejorar la comunicación entre ciudadanos y administradores mediante una plataforma organizada, eficiente y accesible.
